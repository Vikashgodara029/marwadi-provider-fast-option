# Marwadi Provider FastOption

A simple static website demo using virtual coins only.

## Included
- Responsive landing page and brand title
- Lucky Spin mini-game using virtual coins
- No real-money deposits, betting, cash prizes, or withdrawals

## Publish for free (example: Cloudflare Pages)
1. Sign in to your own hosting account.
2. Create a new Pages project and upload/deploy the files in this folder, or connect a Git repository containing them.
3. After deployment, test the public URL on mobile and desktop.

## Important
- This is a static demo. It does **not** include a real Owner Login, admin database, or server-side authentication.
- Do not add passwords or secret keys to `script.js` or other public files.
- For a real owner/admin system, add a secure server-side backend and database.
- A free hosting plan may have limits; a custom domain is usually optional and may cost extra.
